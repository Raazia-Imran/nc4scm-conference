# Conference fonts

Local copies of the same font families and weights used in the approved stylesheet, fetched on 31 October 2026 from the Google Fonts CSS response:

https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500;600&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap

`fonts.css` maps conference-1 through conference-4 to DM Sans weights 300, 400, 500 and 600; conference-5 through conference-8 to Plus Jakarta Sans weights 400, 500, 600 and 700. These are static TrueType files served by the official fonts.gstatic.com URLs returned by that CSS request. They are served locally to avoid third-party font connections on page visit.

The respective SIL Open Font License notices are included as DM-Sans-LICENSE.txt and Plus-Jakarta-Sans-LICENSE.txt, obtained from the official google/fonts repository.
